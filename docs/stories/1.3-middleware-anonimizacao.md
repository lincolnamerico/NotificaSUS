## Story
**As a** cidadao que deseja reportar um incidente anonimamente,
**I want** que meus dados pessoais (IP, user-agent, headers identificaveis) sejam removidos antes de persistir a notificacao,
**so that** minha identidade seja protegida em conformidade com a LGPD.

## Acceptance Criteria
1. Middleware de anonimizacao executa antes de qualquer persistencia no banco
2. Quando `anonimo=true`, os seguintes dados sao descartados: IP do cliente, User-Agent, headers identificaveis (Authorization, Cookie, X-Forwarded-For)
3. Nenhum log contem dados pessoais quando modo anonimo ativo
4. Termo de consentimento LGPD exibido antes da submissao (checkobrigatorio)
5. Toggle "Modo Anonimo" visivel no topo do formulario, ativado por padrao
6. Mesmo com `anonimo=false`, apenas dados minimos necessarios sao persistidos (campos do formulario, sem IP/user-agent)
7. Suite de testes automatizados validam que IP nao vaza para o banco em modo anonimo
