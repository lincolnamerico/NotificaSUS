## Story
**As a** gestor municipal de saude de Pinhais/PR,
**I want** acessar o dashboard em um subdominio segregado (`gestao.pinhais.pr.gov.br`),
**so that** a area de gestao seja isolada do formulario publico por seguranca e organizacao.

2. Variavel de ambiente `NEXT_PUBLIC_GESTAO_URL` define a URL do subdominio

4. Configuracao de `next.config.ts` para suportar subdominio com assetPrefix e basePath se necessario
5. Documentacao no README sobre configuração de DNS e subdominio
6. Verificaçao de ambiente: em dev local, `/gestao/*` funciona normalmente sem subdominio
7. Cookies de sessao configurados para funcionar entre subdominios (`.pinhais.pr.gov.br`)
8. Teste de build valida que assets carregam corretamente no subdominio

## Dev Notes

**Configuracao de Cookie para Subdominio**:
No NextAuth v5, configurar cookies com domain compartilhado:
```ts
cookies: {
  sessionToken: {
    name: process.env.NODE_ENV === "production" ? "__Secure-authjs.session-token" : "authjs.session-token",
    options: {
      domain: ".pinhais.pr.gov.br",
      httpOnly: true,
      sameSite: "lax",
      secure: process.env.NODE_ENV === "production",
    },
  },
}
```

**next.config.ts**:
```ts
const gestaoUrl = process.env.GESTAO_URL;
const isGestaoSubdomain = process.env.VERCEL_URL?.startsWith("gestao.");

const config: NextConfig = {
  ...(isGestaoSubdomain && gestaoUrl ? { assetPrefix: gestaoUrl } : {}),
  async redirects() {
    if (process.env.NODE_ENV === "production" && gestaoUrl) {
      return [
        {
          source: "/gestao/:path*",
          destination: `${gestaoUrl}/:path*`,
          permanent: true,
        },
      ];
    }
    return [];
  },
};
```

**Variaveis de Ambiente**:
- `GESTAO_URL=https://gestao.pinhais.pr.gov.br` — URL completa do subdominio
- `NEXT_PUBLIC_GESTAO_URL=https://gestao.pinhais.pr.gov.br` — URL publica para o frontend

**Nota**: No Vercel, subdominio pode ser configurado como projeto separado com mesmo codigo
e variavel `VERCEL_URL` apontando para `gestao.pinhais.pr.gov.br`.
