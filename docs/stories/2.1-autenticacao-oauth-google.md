## Story
**As a** gestor municipal de saúde de Pinhais/PR,
**I want** fazer login no sistema via Google OAuth com email @pinhais.pr.gov.br,
**so that** eu possa acessar o dashboard gerencial com meus dados e permissões corretas.

## Acceptance Criteria
1. Botão "Entrar com Google" na página `/gestao/login` redireciona para o fluxo OAuth do Google
2. Apenas emails com domínio `@pinhais.pr.gov.br` são autorizados (bloqueio já existe em `src/lib/auth/auth.ts`)
3. Após login bem-sucedido, usuário é redirecionado para `/gestao/dashboard`
4. Usuário é cadastrado automaticamente na tabela `usuario` no primeiro login (nome, email, papel padrão "gestor")
5. Sessão expira após 24h de inatividade (configurável via `AUTH_SECRET`)
6. Botão "Sair" no dashboard encerra a sessão e redireciona para `/gestao/login`
7. Middleware de proteção: rotas `/gestao/*` redirecionam para login se não autenticado
8. Exibir nome e email do usuário logado no header do dashboard
