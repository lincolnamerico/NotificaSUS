## Story
**As a** cidadao que acessa o formulario via QR Code,
**I want** que a rota `/notificar?usf=slug` carregue automaticamente o nome da USF e exiba o formulario de notificacao,
**so that** eu nao precise digitar informacoes da unidade e possa focar no relato do incidente.

## Acceptance Criteria
1. Rota `/notificar` renderiza pagina publica com layout responsivo mobile-first
2. Parametro `?usf=slug` na URL consulta a USF no banco e exibe o nome no topo do formulario
3. Se o slug nao existir, exibe mensagem amigavel: "Unidade de saude nao encontrada. Verifique o QR Code."
4. Se nenhum `usf` for informado, exibe campo de selecao para escolher a USF manualmente
5. Rota `GET /api/usf` retorna lista de USFs ativas em formato JSON
6. USFs inativas (ativo=false) nao aparecem na API nem no seletor
7. Pagina carrega em < 2 segundos em conexao 3G (budget de performance)
8. Layout segue padrao visual do municipio de Pinhais/PR (cores institucionais, brasao)

## Dev Notes

**API Specification**:
- `GET /api/usf` — Listar USFs ativas
  - Response: `[{ id: uuid, slug: string, nome: string }]`
  - Filtro: apenas `ativo = true`
[Source: docs/architecture.md#6-api-specification]

**Data Models**:
- USF: id (UUID), slug (VARCHAR 50), nome (VARCHAR 200), endereco (TEXT), ativo (BOOLEAN)
- Query: `SELECT id, slug, nome FROM usf WHERE ativo = true ORDER BY nome`
[Source: docs/architecture.md#4-data-models]

**File Locations**:
- Pagina: `src/app/notificar/page.tsx`
