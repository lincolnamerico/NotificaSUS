## Story
**As a** cidadao que concluiu uma notificacao,
**I want** ver uma tela de confirmacao com meu numero de protocolo unico,
**so that** eu tenha um comprovante do registro e possa acompanhar se necessario.

## Acceptance Criteria
1. Apos submeter o formulario (Step 3 da Story 1.4), o sistema chama `POST /api/notificar` e redireciona para tela de confirmacao
2. Tela de confirmacao exibe numero de protocolo no formato `NOT-YYYYMMDD-XXXX` (ex: NOT-20260728-A3F2)
3. Tela de confirmacao exibe resumo da notificacao (tipo, data, USF, grau)
4. Animacao visual de sucesso (check verde ou similar)
5. Instrucoes claras: "Guarde seu protocolo. Nao e possivel consultar o status por ser um registro anonimo."
6. Botao "Nova Notificacao" que redireciona para o formulario limpo (`/notificar?usf=slug`)
7. Endpoint `POST /api/notificar` cria notificacao no banco com dados do formulario + middleware de anonimizacao
8. Protocolo e unico e gerado com hash curto (colisao tratada com retry)

## Dev Notes

**API Specification**:
- `POST /api/notificar` — Criar notificacao
- Body: `{ usf_id, tipo_incidente, data_hora, descricao, grau_dano, acoes_tomadas, anonimo }`
- Response: `{ protocolo: "NOT-20260728-A3F2", success: true }`
- Erro: `{ error: "mensagem", success: false }`
[Source: docs/architecture.md#6-api-specification]

**Geracao de Protocolo**:
- Formato: `NOT-YYYYMMDD-XXXX`
- XXXX = 4 caracteres alfanumericos (hash curto)
- Exemplo: `NOT-20260728-A3F2`
- Tratar colisao com retry (ate 3 tentativas)
[Source: docs/architecture.md#4-data-models]

**Data Model - Notificacao**:
- id: UUID, protocolo: VARCHAR(20), usf_id: UUID FK
- tipo_incidente: VARCHAR(100), data_hora: TIMESTAMPTZ
- descricao: TEXT, grau_dano: ENUM(leve, moderado, grave, obito)
- acoes_tomadas: TEXT, anonimo: BOOLEAN, created_at: TIMESTAMPTZ
[Source: docs/architecture.md#4-data-models]

**Flow**:
```
Formulario (Step 3) -> POST /api/notificar
  -> Middleware de Anonimizacao (Story 1.3)
  -> Gera protocolo
  -> Persiste no banco
  -> Retorna { protocolo }
-> Redirect para /notificar/confirmacao
```
[Source: docs/architecture.md#10-core-workflows]

**File Locations**:
- Endpoint: `src/app/api/notificar/route.ts`
- Protocolo utils: `src/utils/protocolo.ts`
- Confirmacao: `src/app/notificar/confirmacao/page.tsx`
[Source: docs/architecture.md#7-project-structure]
