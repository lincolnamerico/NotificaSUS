## Story
**As a** desenvolvedor do projeto,
**I want** configurar o ambiente de desenvolvimento com Next.js 14+, Tailwind CSS, Drizzle + Neon, NextAuth v5 e as ferramentas de qualidade,
**so that** a equipe possa iniciar o desenvolvimento das funcionalidades do NotificaSUS com toda a infraestrutura tecnologica pronta.

## Acceptance Criteria
1. Projeto Next.js 14+ (App Router) inicializado com TypeScript 5.x
2. Tailwind CSS 3.x configurado e funcional
3. Drizzle ORM configurado com conexao a Neon PostgreSQL (database URL via .env)
4. Schema inicial do banco criado (tabelas: usf, notificacao, usuario) conforme `docs/architecture.md#4-data-models`
5. NextAuth v5 configurado com provedor OAuth Google (credenciais via .env)
6. Estrutura de diretorios conforme `docs/architecture.md#7-project-structure`
7. Scripts de lint, typecheck e test configurados no package.json
8. Vitest configurado para testes unitarios
9. .env.example criado com todas as variaveis necessarias
10. Projeto compila sem erros (`npm run build`)

## Dev Notes

**Data Models**:
- Tabela `usf`: id (UUID), slug (VARCHAR 50), nome (VARCHAR 200), endereco (TEXT), ativo (BOOLEAN), created_at (TIMESTAMPTZ)
- Tabela `notificacao`: id (UUID), protocolo (VARCHAR 20), usf_id (UUID FK), tipo_incidente (VARCHAR 100), data_hora (TIMESTAMPTZ), descricao (TEXT), grau_dano (ENUM: leve, moderado, grave, obito), acoes_tomadas (TEXT), anonimo (BOOLEAN), created_at (TIMESTAMPTZ)
- Tabela `usuario`: id (UUID), email (VARCHAR 255), nome (VARCHAR 200), papel (ENUM: admin, gestor, visualizador), created_at (TIMESTAMPTZ)
[Source: docs/architecture.md#4-data-models]

**Tech Stack**:
- Next.js 14+ (App Router), TypeScript 5.x, Tailwind CSS 3.x
- Neon PostgreSQL 16 + Drizzle ORM
- NextAuth v5 (OAuth Google)
- Vitest (testes), Sentry (monitoramento)
[Source: docs/architecture.md#3-tech-stack]

**Database Connection**:
Configurar Drizzle com `@neondatabase/serverless` para conexao serverless ao Neon.
DATABASE_URL no formato: `postgresql://user:password@ep-xxx.us-east-2.aws.neon.tech/neondb?sslmode=require`
[Source: docs/architecture.md#5-database-schema]

**Environment Variables**:
- `DATABASE_URL` — string de conexao Neon PostgreSQL
- `AUTH_SECRET` — secret do NextAuth
- `AUTH_GOOGLE_ID` — Google OAuth client ID
- `AUTH_GOOGLE_SECRET` — Google OAuth client secret
- `SENTRY_DSN` — (opcional, para monitoramento futuro)

**Testing**:
